# Cybersecurity Blog & Write-ups Archive (Static)

[![Static Site Deployment](https://img.shields.io/badge/Deployment-GitHub_Pages-blue?style=flat-square)](https://0bkp.github.io/blog/)
[![Security Focus](https://img.shields.io/badge/Focus-Cybersecurity-red?style=flat-square)]()

A custom-built WordPress project migrated to a high-performance static site. This repository serves as a **permanent, read-only archive** of my technical blog, focusing on Pen-testing labs (HTB/TryHackMe) and security research.

> **Note:** This project was originally a live WordPress site. To ensure long-term availability after the original domain expired, it has been decoupled from its backend and converted into a static archive.

## 🎯 Purpose
The goal was to preserve technical write-ups while achieving:
* **Zero-Maintenance:** No database or PHP vulnerabilities.
* **Persistence:** Hosted for free on GitHub Pages.
* **Performance:** Lightning-fast load times through static HTML.

## 🛠 Tech Stack
* **Original Engine:** WordPress (Custom Theme developed from scratch)
* **Frontend:** Semantic HTML5, CSS, JavaScript
* **Static Transition:** Simply Static (WP plugin)
* **Hosting:** GitHub Pages

## 🚀 Key Features
* **Handcrafted UI:** The original WordPress theme was designed specifically for code readability and technical documentation.
* **Write-up Archive:** Detailed walkthroughs of HackTheBox machines and security case studies.
* **Serverless Architecture:** Fully optimized for speed and security by removing the WordPress core dependencies.

## 📁 Project Structure
* `/blog` - The core archive of all security articles.
* `/wp-content` - Optimized assets (images, CSS, JS) extracted from the custom theme.
* `index.html` - Main landing page.
